# 安全边界

适用环境为同一可信 LAN 或已建立加密的设备级私有网络，如 Tailscale。HTTP 加设备令牌不构成端到端加密。不要把端口映射到公网，不要关闭 HTTPS 证书验证。

## 已实现的措施

- CLI 默认 127.0.0.1；GUI 用户选择“创建连接”后，枚举本机活动网卡并选择一个明确的私有 IPv4，无可用网络则回退回环。保留手动设置。Host 仅接受明确的 RFC1918、回环、Tailscale CGNAT 或 IPv6 ULA 地址；拒绝公网和通配监听，不广播或扫描远端。
- 本地开启一次性 8 位配对码，10 分钟有效；用一次即失效。60 秒内最多允许 5 次失败尝试。该全局限制可能被不可信 LAN 设备用于暂时阻断配对，所以只适用于可信网络。
- 输入配对码后仍由 Host 本地确认设备；配对查询使用不可预测、短时的请求密钥并放在请求体内。成功令牌只返回一次。丢失响应需重新配对。
- 设备令牌由 secrets 生成，Host SQLite 仅存 SHA-256；撤销后受保护 API 立即失效，上传结束前再次验证授权。
- 用户复制的连接信息包含一次性短时配对码，属于临时秘密。仅粘贴到本人的另一台电脑；不写入 preferences.json。访问令牌不会出现在连接信息中。主机仍须本地核对并批准新设备。
- 本地管理界面/控制台掌握批准和撤销操作，远端无管理 API。
- 任务和附件校验已认证设备身份，不信任正文自称的 sender；第三设备不能查询任务、草稿和附件。
- 上传使用 UUID 路径。拒绝路径分隔符、绝对路径、控制字符、Windows 保留名。下载端再次验证文件名；同名不覆盖。
- 文件按块传输，校验大小和 SHA-256，落盘复核后才标记可用；下载损坏则删除临时文件。
- 不自动执行或解压任何附件。不读取 Codex、ChatGPT 或其他 Agent 的登录信息。
- 不记录任务正文、附件内容、配对请求体或访问令牌；Uvicorn 访问日志默认关闭。API 错误不回显验证输入。
- Client 只使用明确允许的系统凭据库后端；不可用时只保留内存授权，不降级到明文文件。

## 本地数据

### Skill 后台进程与本地控制

Agent Bridge skill 使用独立 AgentBridge 数据根目录和端点身份；同机不同 Agent 使用不同 profile。`setup` 自动选一个明确的私有接口，CLI 的本地控制 API 另监听随机回环端口，并要求系统凭据库中的控制令牌。局域网服务不暴露控制 API，不能通过 LAN 开启配对、批准、撤销、读取本地任意路径或停止进程。

后台身份与对端访问令牌只存入允许的系统凭据库。skill 需要跨独立命令复用身份，凭据库不可用时拒绝启动，不能使用文件明文回退。此前桌面原型的内存授权回退不用于此模式。运行状态文件只存 PID、实例 ID 和本地控制 URL，不含令牌。

Skill 默认只发送显式选择的普通文件和 UTF-8 报告，拒绝目录和符号链接，不自动扫描项目。交付在独立收件目录导出，检查大小与哈希；报告内容是远端数据，不授权执行附件或更改项目。收到、收取与已读分别记录。已读不构成代码验收或接收端已开始开发的证明。

安装包提供 SHA-256 清单防止文件意外改变，不代表发布者可信或经过安全审计。升级仅在旧文件仍与旧清单一致时进行，保留 .runtime 和额外用户文件；存在用户修改或新路径冲突时拒绝自动覆盖。

SQLite、缓存和附件包含用户任务内容，未进行静态加密。请依赖操作系统用户权限、磁盘加密和设备访问控制。不要与不可信用户共享数据目录。撤销远端设备不会删除其已下载文件或离线缓存。

配置文件保存设备 UUID、非秘密地址、目录等信息，不保存令牌。导出包只包含任务与显式附件，若用户在正文或附件放入秘密，程序无法自动消除；上传前自行检查。
