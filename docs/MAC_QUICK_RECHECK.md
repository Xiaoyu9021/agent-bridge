# Mac：复核 V0.1.1 简化界面

Mac 的 V0.1.0 回传已被 Windows 审阅，42 项测试、512 MiB、Keychain 和 `.app` 证据已保留。本次依据用户反馈，简化了首次启动和设备连接，版本为 0.1.1。

请先读 AGENTS.md、CHANGELOG.md，以及本文件，再执行以下工作。不重写项目，不扩展 V0.2，不将旧 Mac 证据当作本次结果。

1. 使用独立副本或保留本机旧版本，按 pyproject.toml 更新虚拟环境。不要使用 Windows 依赖快照。
2. 运行 `python -m ruff check .`、`python -m pytest -q`（Windows 当前为 53 项），再执行 `python -m codex_bridge --self-check artifacts/macos-source-smoke-0.1.1.json`。命令中的 python 指向本项目 .venv。
3. 用全新 `--data-dir` 原生启动：确认“加入连接”只需要粘贴一段连接信息，IP、端口等字段默认隐藏；macOS 默认选“加入连接”。确认高级设置仍能打开，中文不截断。
4. 验证两个独立本机实例的邀请和确认流程。创建连接端如需只在本机测试，可在高级设置明确设为 127.0.0.1，再用手动连接备用方式；真实用户流程使用私有网络。两端均不得跳过本机批准。
5. 执行 `sh scripts/build_macos.sh`，运行 `.app` 中的 `--self-check`，再实际打开新版 `.app`。为用户保留该新版应用，告诉用户其路径；不要只修改源码却继续打开旧 app。
6. 检查再次启动是否直接进入任务页，无需重填表单。主界面只保留“连接另一台电脑”；接收任务后下一步自动变为“开始处理”，结果通过“回传结果”提交。

没有改动传输实现，无需例行重复 512 MiB 性能测试；若发现并修改了传输相关问题，则重新执行针对性测试。保持安全边界，连接码和令牌不写入明文配置、报告或日志。

Windows ↔ Mac 实际双机测试仍需要两端程序同时打开。没有收到 Windows 复制的连接信息前，不扫描网络、不猜测地址、不声称跨机通过。

在 MAC_RECHECK_0_1_1.md 记录版本、命令结果、原生操作和未完成项。若有修复，回传报告、修改文件（保留相对路径）及脱敏证据；不回传 .venv、用户数据库、凭据或整套构建目录。用户只需使用你在 Mac 上生成的新版 `.app`。
